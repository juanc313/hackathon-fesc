cargan como NULL: 'nom1 + " " + nom2' lanzaba TypeError y la API devolvía 500.

lanzaba KeyError con un código de estado inválido.

== Corrección aplicada ==
$ sed -n '22,31p' services/api/app.py
# LEFT JOIN: un afiliado sin empresa en EMPRESA debe seguir respondiendo (con
# empresa vacía) en vez de desaparecer y provocar un 404 falso. Los CSV del
# origen traen campos opcionales vacíos, que \copy carga como NULL; por eso
# también se usa COALESCE.
QUERY = """
SELECT a.nro_doc, a.nom1, a.nom2, a.ape1, a.ape2, a.est_afi, COALESCE(e.nom_emp, '')
FROM afi_mae a

WHERE a.nro_doc = %s
LIMIT 1

== Verificación de la respuesta contra las huellas del validador ==
En este equipo no hay motor de Docker, así que la API no se pudo levantar contra
PostgreSQL real y no se guarda aquí ninguna salida de `curl`. Lo que sí se puede
comprobar es la lógica de la consulta: se reproduce sobre los mismos datos que
carga la base (db/init/02_load.sql toma los CSV de data/ con \copy, que carga los
campos vacíos como NULL) y el resultado se contrasta con las huellas de
.validator.json, que es lo que evalúa la prueba T06 del validador.

$ python3 - <<'PY'
import csv, hashlib, json
pub = json.load(open(".validator.json", encoding="utf-8"))
def fp(v): return hashlib.pbkdf2_hmac("sha256", v.encode(), pub["salt"].encode(), 200000).hex()
def filas(p):
    with open(p, encoding="utf-8", newline="") as fh:
        return [{k: (v if v != "" else None) for k, v in r.items()} for r in csv.DictReader(fh)]
mae, emp = filas("data/AFI_MAE.csv"), filas("data/EMPRESA.csv")
nom_emp = {r["COD_EMP"]: r["NOM_EMP"] for r in emp}
ESTADOS = {"A": "ACTIVO", "I": "INACTIVO"}
def respuesta(doc):
    fila = [x for x in mae if x["NRO_DOC"] == doc]
    if not fila:
        return None
    r = fila[0]
    nombre = " ".join(p for p in (r["NOM1"], r["NOM2"], r["APE1"], r["APE2"]) if p)
    estado = ESTADOS.get(r["EST_AFI"], r["EST_AFI"] or "DESCONOCIDO")
    empresa = nom_emp.get(r["COD_EMP"], "") if r["COD_EMP"] else ""
    return " ".join(nombre.split()), estado, empresa

for caso in pub["api_sample"]:

    llave = "|".join([" ".join(nombre.upper().split()), estado.upper(), empresa])
    print("{0}  {1}  nombre={2!r} estado={3!r} empresa={4!r}".format(
        doc, "huella COINCIDE con .validator.json" if fp(llave) == caso["hash"] else "huella NO COINCIDE",
        nombre, estado, empresa))
doc = pub["known_document"]
print("{0}  (documento conocido del contrato)  {1}".format(doc, respuesta(doc)))
doc = pub["missing_document"]
print("{0}  {1}".format(doc, "sin filas en el maestro: la API responde 404" if respuesta(doc) is None else respuesta(doc)))
